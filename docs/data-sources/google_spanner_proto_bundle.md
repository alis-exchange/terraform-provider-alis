# alis_google_spanner_proto_bundle (Data Source)

Reads the types a Cloud Spanner database's proto bundle holds for the given proto packages. A bundle holding none of them (or no bundle at all) is an error, so this data source doubles as a guard for tables with `PROTO` columns whose bundle is managed elsewhere.



## Example Usage

```terraform
data "alis_google_spanner_proto_bundle" "books" {
  project  = var.GOOGLE_PROJECT
  instance = var.SPANNER_INSTANCE
  database = "tf-test"
  packages = ["com.example.books.v1"]
}

output "books_proto_types" {
  value = data.alis_google_spanner_proto_bundle.books.types
}
```

## Schema

### Required

- `database` (String) The Spanner database ID whose proto bundle is read.
- `instance` (String) The Spanner instance ID that contains the database.
- `packages` (Set of String) Proto packages to look up. Only messages and enums directly in these packages are returned; nested packages are not included.
- `project` (String) The Google Cloud project ID containing the Spanner instance and database.

### Read-Only

- `types` (Set of String) Fully qualified names of the messages and enums from `packages` that the bundle holds.
