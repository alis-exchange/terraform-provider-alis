# alis_google_spanner_table_foreign_key (Data Source)

Reads a foreign key constraint of a Cloud Spanner table by name. A constraint that does not exist is an error. See https://cloud.google.com/spanner/docs/foreign-keys/overview



## Example Usage

```terraform
data "alis_google_spanner_table_foreign_key" "orders_book" {
  project  = var.GOOGLE_PROJECT
  instance = var.SPANNER_INSTANCE
  database = "tf-test"
  table    = "orders"
  name     = "FK_orders_book"
}

output "orders_book_on_delete" {
  value = data.alis_google_spanner_table_foreign_key.orders_book.on_delete
}
```
