# function: resource_name_ancestor_ddl

Generates a `computation_ddl` expression for `alis_google_spanner_table` computed columns that extracts the ancestor prefix of an [AIP-122](https://google.aip.dev/122) resource name, up to and including the ID of the last given collection. The generated `REGEXP_EXTRACT` always has exactly one capturing group, which Spanner requires.

For example `provider::alis::resource_name_ancestor_ddl("Book.name", "shelves")` returns
`REGEXP_EXTRACT(Book.name, r'^(shelves/[^/]+)')`, extracting `shelves/123` from `shelves/123/books/456`.



## Example Usage

```terraform
# Generates:
# REGEXP_EXTRACT(Book.name, r'^(shelves/[^/]+)')
# extracting "shelves/123" from "shelves/123/books/456".
output "parent_ddl" {
  value = provider::alis::resource_name_ancestor_ddl("Book.name", "shelves")
}

# Nested collections extend the prefix. Generates:
# REGEXP_EXTRACT(Book.name, r'^(shelves/[^/]+/books/[^/]+)')
output "book_ancestor_ddl" {
  value = provider::alis::resource_name_ancestor_ddl("Book.name", "shelves", "books")
}
```
