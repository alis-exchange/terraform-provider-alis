# function: resource_name_id_ddl

Generates a `computation_ddl` expression for `alis_google_spanner_table` computed columns that extracts the resource ID following a collection segment in an [AIP-122](https://google.aip.dev/122) resource name. The generated `REGEXP_EXTRACT` always has exactly one capturing group, which Spanner requires.

For example `provider::alis::resource_name_id_ddl("Book.name", "books")` returns
`REGEXP_EXTRACT(Book.name, r'books/([^/]+)')`, extracting `456` from `shelves/123/books/456`.



## Example Usage

```terraform
# Generates:
# REGEXP_EXTRACT(Book.name, r'books/([^/]+)')
# extracting "456" from "shelves/123/books/456".
output "book_id_ddl" {
  value = provider::alis::resource_name_id_ddl("Book.name", "books")
}
```
